myconsole icon set

Paste one of these paths into an item's Icon field in Fully Kiosk → Universal Launcher → Select Items to Show. The paths below are read from wherever this page is open, so they match your actual folder.

These are the 256px PNGs. Fully Kiosk decodes a shortcut icon into a bitmap instead of rendering it in the WebView, so it will not take the .svg files — those are just the editable sources.

Re-render the PNGs after editing an SVG with tools/make-png.sh.
